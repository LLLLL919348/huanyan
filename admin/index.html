邀请码准入读取中…
现在是什么状态

开启后：网站内容所有人可见（资源、角色、设定都能浏览），但与角色对话必须先通过邀请码。判定全部在服务端 —— 前端只是显示；停用或删除某个邀请码，已经拿到凭证的人也会立刻失效。

生成新邀请码

有效天数填 0 表示永久有效；「访客凭证有效期」是对方通过之后，这台设备被记住多少天。

已发出的邀请码

「对话轮数」只统计这个码名下的模型调用次数，用来观察谁在用、用了多少 —— 不设上限，也不影响额度规则（额度仍按访客每天 N 次算）。

怎么用
  1. 打开「开启邀请制」，生成邀请码（可以一次生成多个，也可以填备注）。
  2. 把码发给指定的人（微信/私信都行，码形如 ABCD-EFGH-JKLM-NPQR）。
  3. 对方打开网站 → 右上角「邀请码」→ 输入一次 → 这台设备之后就能直接对话了。
  4. 要收回：把那一行「停用」，或者直接删除 —— 已发出的凭证随之作废。
