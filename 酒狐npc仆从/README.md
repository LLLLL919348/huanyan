# 酒狐npc仆从

Terraria **tModLoader 1.4.4** 的自定义仆从模组：一只跟着玩家跑、能战斗、能聊天、能喂食、能摸摸头的狐狸女仆「酒狐」。

> 这个目录是「幻言」仓库里的一个子项目，和站点代码互不影响。

## 目录结构

| 路径 | 内容 |
|---|---|
| `酒狐.cs` | 核心：NPC 定义、动画帧、绘制、摸摸头、低血庇护、梦云水晶等 |
| `酒狐NPC状态.cs` | 状态机、目标选择、寻路/传送、骑扫帚等行为 |
| `酒狐攻击.cs` | 攻击流程、武器判定、法术/近战/冲刺 |
| `酒狐任务执行.cs` | 任务系统（恋还是练、寻宝、闲聊等） |
| `酒狐互动UI.cs` / `酒狐任务UI.cs` / `酒狐图鉴UI.cs` | 三套界面 |
| `酒狐玩家.cs` / `酒狐饰品.cs` | 玩家侧状态与 20+ 件饰品 |
| `Content/Images/酒狐/` | 原皮肤贴图（站 40×56、跑 40×168、战斗 240×56、摸摸 720×56） |
| `Content/Images/酒狐/新皮肤/` | 蓝发女仆皮肤（见下） |
| `Localization/` | 9 个语种的 `.hjson` 文本 |
| `报错/` | 贴图生成/量产脚本（不参与编译，也不会被打包） |

## 编译

需要 tModLoader 的「模组开发」环境（`tModLoader.targets` 引用的那套）。

```powershell
dotnet build "酒狐npc仆从.csproj" -v q --nologo
```

编译成功会把 `酒狐npc仆从.tmod` 输出到 `Documents\My Games\Terraria\tModLoader\Mods\`，进游戏「模组」页刷新即可启用。

## 新皮肤

客户端配置里勾选 **设置 → 模组配置 → 酒狐任务配置 → 使用新皮肤（蓝发女仆装）** 才生效，默认关闭。

- 三张核心贴图任意一张缺失 / 加载失败都会整体回退到原皮肤，不影响存档。
- 帧布局：`zhanli.png` 单帧 40×56，`paobu.png` 3 帧 40×168（竖排），`Armor_zhandou.png` 6 帧 240×56（横排）。
- 代码里的 `取帧区域()` 会自动识别**竖排/横排**两种布局，所以贴图横竖排都能用。
- `petpet_sheet.png` 摸头表固定 10 帧 × 72×56 = 720×56，缺省时用原皮肤的摸摸表。

## 贴图是怎么量产的

`报错/` 里是生成脚本，思路参考 [PixelOE](https://github.com/KohakuBlueleaf/PixelOE)（对比度感知的轮廓扩张 + 不做平均的降采样）：先把高对比细节（眼线、瞳孔）加粗，再按块取**主导色**缩到 40×56，最后按 5 类（皮肤 / 眼白 / 眼线 / 虹膜 / 嘴）逐块归类补回脸部像素点。

| 脚本 | 用途 |
|---|---|
| `pxoe.ps1` | 主管线：去背景 → 细节扩张 → 主导色降采样 → 调色板量化 → 描边 → 脸部按类重建 |
| `petsheet.py` / `petsheet.ps1` | 把摸摸头动画（gif/webp 或单帧）拼成 720×56 摸头表 |
| `extract_frames.py` | 拆 gif / webp 动画帧 |
| `up.ps1` / `crop.ps1` | 放大预览、裁切（检查像素用，最近邻，不模糊） |

用法示例：

```powershell
.\报错\pxoe.ps1 -InFile 原图.jpg -OutFile zhanli.png
python .\报错\petsheet.py petpet.gif petpet_sheet.png 72 56 52
```
